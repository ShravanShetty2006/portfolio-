# 3D Portfolio (React + MUI + React Three Fiber)
Install: `npm install` · Dev: `npm run dev` · Build: `npm run build`
Edit your content in `src/data/*.ts` and `index.html` (title/meta). Theme colors: `src/theme/theme.ts`.
Contact form: copy `.env.example` to `.env` and set `VITE_FORM_ENDPOINT` (e.g. Formspree). Without it, only the email button shows.
